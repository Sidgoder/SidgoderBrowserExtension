# OnlyTab

一个基于 `Manifest V3` 的轻量浏览器扩展，用于替换浏览器新标签页，提供搜索、时间、天气和背景自定义能力。

## 功能

- 替换 Chrome 或 Edge 默认新标签页
- 显示当前时间、日期、位置和实时温度
- 支持 Bing、Google、DuckDuckGo、Baidu 搜索引擎切换
- 支持搜索历史记录、快速复搜、单条删除和全部清空
- 支持英文和简体中文界面
- 支持浅色与深色主题
- 支持默认背景、图片背景和视频背景
- 支持背景遮罩透明度调节
- 支持本地保存用户设置

## 安装

1. 打开 Chrome 或 Edge 扩展管理页面。
2. 启用“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择当前项目目录。

## 权限说明

- `geolocation`：用于获取当前位置并显示天气信息。
- `storage`：用于保存搜索引擎、语言、主题、背景等用户设置。
- `https://api.open-meteo.com/*`：用于获取天气数据。
- `https://api.bigdatacloud.net/*`：用于根据经纬度获取位置名称。
